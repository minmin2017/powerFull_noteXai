# HTTPS สำหรับมือถือ (แก้ปัญหาไมค์บน iPhone)

ทำไมต้องมี: มือถือ (Safari/Chrome) จะขอสิทธิ์ไมค์ (`getUserMedia`) ได้ก็ต่อเมื่อหน้าเว็บโหลดผ่าน
HTTPS หรือ `localhost` เท่านั้น — เข้าผ่าน `http://192.168.x.x:4321` (ธรรมดา) จะถูกบล็อกเงียบๆ
เซิร์ฟเวอร์นี้เลยเปิดพอร์ต HTTPS เพิ่ม (ค่าเริ่มต้น **4443**) คู่ไปกับพอร์ต HTTP เดิม (4321)
โดยใช้ใบรับรองที่สร้างเองด้วย `mkcert` (ไฟล์ `cert.pem` / `key.pem` ในโฟลเดอร์นี้ — ไม่ commit เข้า git)

## ติดตั้งบน iPhone (ทำครั้งเดียว)

1. เปิด **Safari** บน iPhone (ต้องอยู่ WiFi วงเดียวกับคอมเครื่องนี้)
2. เข้า `http://<IP คอมนี้>:4321/rootCA.pem` (เช่น `http://192.168.1.45:4321/rootCA.pem`)
3. Safari จะถามว่าจะติดตั้ง "configuration profile" — กด **Allow** แล้วปิดแอปนี้ไป
4. ไปที่ **Settings → General → VPN & Device Management** (หรือ "Profile Downloaded")
   กด profile ที่ชื่อ `mkcert ...` แล้วกด **Install** (ใส่รหัสผ่านเครื่องถ้าถาม) 2 รอบ
5. **สำคัญ**: ไปที่ **Settings → General → About → Certificate Trust Settings**
   เปิดสวิตช์ **Full Trust** ให้ certificate ตัวนี้ (ขั้นตอนนี้พลาดบ่อยที่สุด ถ้าข้ามจะยังใช้ไมค์ไม่ได้)
6. กลับไปเปิดแอปใหม่ผ่าน **`https://<IP คอมนี้>:4443`** (พอร์ต **4443** ไม่ใช่ 4321!) —
   ควรเห็นแม่กุญแจล็อกบน address bar ไม่มี warning แล้ว ลองกดไมค์ได้เลย

## หมายเหตุ

- ใช้ได้เฉพาะตอนมือถืออยู่ WiFi เดียวกับคอมเครื่องนี้ (ไม่ใช่ 4G/5G) — เพราะเป็น IP วง LAN
- ถ้า IP ของคอมเปลี่ยน (เช่น router แจก IP ใหม่) ต้องสร้าง cert ใหม่ให้ครอบ IP ใหม่ด้วย:
  `mkcert -key-file key.pem -cert-file cert.pem <IP ใหม่> 127.0.0.1 localhost`
  แล้ว restart เซิร์ฟเวอร์
- ลืมพอร์ต 4443 ก็ไม่เป็นไร เปิด 4321 (HTTP) จากมือถือได้เหมือนเดิม แค่ไมค์จะใช้ไม่ได้เท่านั้น
  ฟีเจอร์อื่นทั้งหมด (แชท, canvas, ฯลฯ) ทำงานปกติทั้งสองพอร์ต
